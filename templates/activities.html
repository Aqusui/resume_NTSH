我的課外生活

高中三年除了學校課業之外，我也積極參與不同的 課外活動。透過參加社團、運動、自主學習以及 各種校內活動，我累積了許多寶貴的經驗。

這些活動不只讓我的高中生活更加充實， 也讓我學習到團隊合作、時間管理、 溝通能力以及面對問題時的解決能力。

💻 程式設計與網頁製作

我對資訊科技與程式設計非常有興趣。 在課餘時間，我會利用網路上的教學資源 學習 HTML、CSS、JavaScript 以及 Python。

在製作網頁的過程中，我會自己規劃網站架構、 設計頁面以及處理程式問題。這讓我了解到， 一個完整的作品需要耐心、邏輯思考與不斷嘗試。

HTML CSS JavaScript Python

🏀 運動與體育活動

平常我喜歡參與籃球、跑步等運動。 運動是我在課業之外放鬆心情的重要方式， 也能讓我保持良好的生活習慣。

在團隊運動中，我學習到每個人的角色都很重要。 只有透過溝通與合作，才能讓團隊順利完成目標。 這些經驗也讓我更加重視團隊合作。

籃球 團隊合作 運動

📚 自主學習

除了學校課程之外，我也會利用課餘時間 學習自己感興趣的內容，例如資訊科技、 網頁設計以及其他實用技能。

自主學習讓我了解到，學習不一定只能依靠 課本或老師。只要找到適合自己的方法， 就可以主動探索新的知識。

自主學習 閱讀 資訊科技

🏆 比賽與校園活動

高中期間，我也參與過學校舉辦的各項活動 與比賽。在活動準備過程中，我需要和同學 一起討論、分配工作並安排時間。

即使過程中遇到困難，我也學習不要輕易放棄， 而是和團隊一起尋找解決方法。 這些經驗成為高中生活中很重要的一部分。

比賽 團隊合作 校園活動

🌱 課外活動帶給我的收穫

  • 學習與不同的人溝通及合作。
  • 培養時間管理與規劃能力。
  • 提升遇到問題時分析與解決問題的能力。
  • 透過自主學習探索自己的興趣。
  • 累積高中三年的生活經驗與成長。
  • 更加了解自己未來想發展的方向。
